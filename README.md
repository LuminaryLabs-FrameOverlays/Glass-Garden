# Glass Garden

**Proposal:** OV-064

**Ecosystem:** Glass

Glass Garden is an approved concept for procedural virtual houseplants. Its specific generation and growth mechanics remain to be designed; botanical accuracy is not claimed.

## Intended experience

The proposed experience is to create virtual houseplants and watch them grow over time. A user could return to tend or revisit a personal collection of plants. These are product intentions, not implemented or finalized features; interactions, plant variety, and growth rules still need design.

## Planned integration

The planned direction is to build Glass Garden as a Glass overlay using FrameFactory. The integration and runtime composition have not been implemented or validated.

## Current state

This repository contains documentation only and records the approved concept and intended direction. Repository setup is complete; application implementation has not started. There is no application, runtime, procedural generation, or growth simulation in this repository.
